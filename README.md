# AI × Web3 School — 个人学习仓库

> lebron 的 AI × Web3 学习记录 | 基于 [aiweb3.school](https://aiweb3.school/zh/handbook/)

## 学习目标

用 8 周时间系统掌握 AI + Web3 核心知识，能独立分析 DeAI 项目并动手构建链上 AI Agent 原型。

---

## 学习路径（4 周）

### Week 1 — AI 基础

重点：三类 AI / ML 三大范式 / 深度学习原理 / LLM API 调用 / Prompt Engineering

产出：LLM API 调用 Demo + CH1 笔记。

### Week 2 — Web3 基础

重点：区块链原理 / Solidity 入门 / Remix IDE / DeFi & NFT & DAO 协议拆解 / 读链上数据

产出：Sepolia 测试网合约部署 + CH2 笔记。

### Week 3 — AI × Web3 融合

重点：DeAI 生态（Bittensor / Ocean / Fetch.ai）/ AI Agent 链上集成 / 隐私 AI（ZKP / 联邦学习）

产出：链上 AI Agent 调用 Demo + CH3 笔记。

### Week 4 — 综合项目

重点：选题 + 架构设计 / MVP 实现 / 复盘总结

产出：可展示的 AI × Web3 项目 + 完整复盘文档。
