# AI × Web3 School — 个人学习仓库

> lebron 的 AI × Web3 学习记录 | 基于 [aiweb3.school](https://aiweb3.school/zh/handbook/)

## 学习目标

用 8 周时间系统掌握 AI + Web3 核心知识，能独立分析 DeAI 项目并动手构建链上 AI Agent 原型。

---

## 学习路径（8 周）

### Phase 1 — AI 基础 (Week 1-2)

| Week | 主题 | 重点 |
|------|------|------|
| 1 | AI 核心概念 | 三类 AI / ML 三大范式 / 深度学习原理 |
| 2 | LLM 实战 | GPT/Claude/Gemini API 调用 / Prompt Engineering |

产出：完成 LLM API 调用 Demo，写 2 篇笔记。

### Phase 2 — Web3 基础 (Week 3-4)

| Week | 主题 | 重点 |
|------|------|------|
| 3 | 区块链 & 智能合约 | Ethereum / Solidity 入门 / Remix IDE |
| 4 | DeFi / NFT / DAO | 协议拆解 / 读链上数据 |

产出：部署一个 Sepolia 测试网合约，写 2 篇笔记。

### Phase 3 — AI × Web3 融合 (Week 5-6)

| Week | 主题 | 重点 |
|------|------|------|
| 5 | DeAI 生态 | Bittensor / Ocean Protocol / Fetch.ai 拆解 |
| 6 | AI Agent + 链上集成 | 链上交易自动化 / DAO 治理 Agent |

产出：跑通一个链上 AI Agent 调用流程，写 2 篇笔记。

### Phase 4 — 综合项目 (Week 7-8)

| Week | 主题 | 重点 |
|------|------|------|
| 7 | 项目设计 | 选题 / 架构图 / 技术栈确认 |
| 8 | 实现 & 复盘 | MVP 上线 / 学习总结 |

产出：一个可展示的 AI × Web3 项目 + 完整复盘文档。
