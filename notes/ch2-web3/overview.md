## 2.1 什么是 Web3

互联网下一演进阶段：基于区块链，强调去中心化、用户所有权、透明度。

**Web 演进:**
- Web1: 只读（1990s）
- Web2: 读写，中心化平台（2000s-今）
- Web3: 读写拥有，去中心化（进行中）

---

## 2.2 区块链

分布式账本，数据以块存储并加密链接。

**四大特性:** 不可篡改性 / 透明性 / 去中心化 / 共识机制

**主要网络:**

| 网络 | 特点 |
|------|------|
| Bitcoin | 数字货币，价值存储 |
| Ethereum | 可编程区块链，智能合约 |
| Solana | 高速低费 |
| BNB Chain | 币安生态 |
| Polygon | 以太坊扩展 |
| Avalanche | 高吞吐量 |

---

## 2.3 智能合约

链上自动执行程序，满足条件自动触发。特点：无需中介 / 不可篡改 / 透明可审计。

---

## 2.4 DeFi / NFT / DAO

**DeFi**: 链上金融服务（借贷、交易、流动性挖矿、收益农场）

**NFT**: 唯一数字资产所有权代币（数字艺术 / 游戏 / 虚拟地产）

**DAO**: 智能合约治理的组织，代币持有者参与决策
